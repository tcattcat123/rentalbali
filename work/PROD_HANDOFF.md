## 4. Запуск и проверка локально

```
npm install
npm run dev          # = node server.js, PORT из .env (по умолчанию 3000)
```

Открыть `http://localhost:3000`. Без `.env` и без доступного MySQL сервер стартует с ошибкой подключения - для чисто визуальных правок шапки/темы это не блокирует, если API не нужен, но список объектов тогда пуст.

Проверки:
```
node --check server.js
node --check js/app.js      # синтаксис клиентского файла тоже валиден как скрипт
```

Живая проверка в браузере: кнопки и скриншоты в тестовом браузере недоступны (вьюпорт 0x0), проверять через `evaluate_script`: читать computed-стили шапки, переключать тему кликом по `#themeBtn`, запускать функции `app.js` напрямую. После любой правки CSS/JS замер делать только со свежим `?cb=` в URL, иначе кэш.

Кэш-бустинг: `index.html` дописывает `?v=N` к `css/style.css` и `js/app.js` через `document.write`. Любая правка этих файлов требует поднять число в index.html (14 -> style.css, 479 -> app.js) и обновить `app-build` (index.html:12).

## 6. Прод-топология (для понимания, не для действий)

- Статика nginx: `/var/www/evak11/bali` (index.html, css/, js/, img/) - владелец `www-data:www-data`, режим `644`.
- Node API: `/opt/rentalbali/server.js`, процесс PM2 `rentalbali`. После смены `server.js` обязателен `pm2 restart rentalbali`; первые запросы после рестарта могут дать `http=000` - повторить замер.
- MySQL: docker-контейнер `laravel_db`, база `rentalbali`.
- Канал доступа с этой машины: `bash /c/tmp/evak_run.sh "<команда>"` (plink) и `bash /c/tmp/evak_put.sh <локал> root@94.72.141.91:<дистант>` (pscp). Цепочки держать короткими: длинный конвейер обрывается.
- Локальные файлы в CRLF, на проде LF - перед сравнением нормализовать обе стороны (`tr -d '\r'`), иначе ложные различия.
- Права на статику: `chown www-data:www-data`, `chmod 644`. Права `server.js`: `root:root`, `644`.

Протокол одиночного деплоя файла (обязателен целиком, каждый пункт):
1. `md5sum` прод-файла и сверить с хешем моего последнего деплоя. Не совпало = на проде чужие правки = стоп, докладывать до записи.
2. `diff` прод против локал (с нормализацией CRLF): удаляемые строки = ровно мой переписанный блок, ничего лишнего.
3. Резерв: `cp -a` прод-файла в `/root` с датой в имени.
4. Загрузить один файл в стейдж (`*.new`), `md5sum` стейджа = md5 локального файла, только затем `mv` на место.
5. `chown`/`chmod`, `node --check server.js` (для JS-бэкенда) после `mv`, не на `.new`.
6. При изменении `server.js` - `pm2 restart rentalbali`.
7. `md5sum` финального прод-файла = локальный.
8. curl с User-Agent и `?cb=` (без UA сервер отдаёт 403), проверить содержимое по нужным признакам.
9. Откат - одна строка: восстановить резерв.
