# Bali Villa 7 Bot (Demo)

Telegram bot that **demonstrates guest-facing scenarios to villa owners and
management companies** (not a guest-facing production bot).

When you tap a scenario, the bot "falls into" a simulated conversation that a
real guest would see — with a **pre-filled booking (Villa #7)** and
**services appropriate to the timing**. No booking data is collected.

## Files
- `bot.py` — entry point (long-polling).
- `config.py` — token, scenarios, service-offer matrix, OpenRouter settings.
- `states.py` — FSM states.
- `keyboards.py` — reply keyboards + welcome text.
- `prompts.py` — guest-facing opening prompts per scenario.
- `simulation.py` — builds the pre-filled booking + guest message.
- `knowledge_base.py` — facts for scenarios/services (used to ground AI).
- `ai_client.py` — OpenRouter integration (optional).
- `handlers.py` — all handlers.

## Menu
- **📆 Scenarios** — 6 scenarios:
  1. Pre-arrival — more than 7 days ahead
  2. Pre-arrival — less than 7 days ahead
  3. Villa check-in *(under development)*
  4. Accommodation — 1 day
  5. Accommodation — 3 days or more
  6. Check-out *(under development)*
- **🛎 Services** — 9 services (demo replies).
- 📞 Call Manager — simulated response.
- ↩ Back to menu on every screen.

## Scenario logic
Each active scenario shows a guest message with a pre-filled booking
(dates depend on the scenario) and offers **different services**:
- >7 days: transfer, excursions, driver for the day, romantic setup, SPA
- <7 days: transfer, excursions, SPA, cleaning/laundry/grocery
- 1 day: scooter/bike rental, restaurant, express massage, taxi
- 3+ days: transfer, driver, excursions, SPA, cleaning/laundry/grocery

Tapping an offer shows a guest-facing confirmation.

## AI (OpenRouter, optional)
If `OPENROUTER_API_KEY` is set, guest-facing messages are generated by the AI
and grounded on the knowledge base (facts are searched first, then the AI
composes the answer). Without a key, static templates are used.

## Run
```bash
pip install -r requirements.txt
python bot.py
```

## Environment variables
- `BOT_TOKEN`
- `ADMIN_CHAT_ID` — admin chat id for alerts (0 = off)
- `UPLOADS_DIR`
- `OPENROUTER_API_KEY`, `OPENROUTER_MODEL`, `OPENROUTER_TIMEOUT`
